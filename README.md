# SweetBook — адаптивна лабораторна робота

Використано HTML + CSS без JavaScript.

Функції:
- адаптивність mobile / tablet / desktop;
- CSS Grid + Flexbox;
- @media;
- CSS-only фільтр за категоріями;
- картки рецептів відкривають окремі HTML-сторінки;
- серце «обране» перемикається через checkbox CSS (візуально, без збереження після перезавантаження);
- калорійний фільтр — макет, як і в умові лабораторної.

Важливо: через заборону JavaScript постійне збереження обраного та справжня фільтрація за калоріями не реалізуються.
